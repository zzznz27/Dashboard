# Logo sources

The sample catalogue has no logos: each system's node shows its initials. To add a logo:

1. Get the file from the vendor's own brand or press page, and check its brand guidelines (many ask that logos aren't recoloured; the map draws each mark in white on its node).
2. Sanitise SVGs: remove scripts, event attributes, external references, DOCTYPE and editor metadata.
3. Save it in `src/web/logos/` and add the system to `src/config/logos.json` (`logo` = full-colour logo for the side panel and tooltip; `mark` = the symbol alone, or `null`).
4. Record it in the table below.
